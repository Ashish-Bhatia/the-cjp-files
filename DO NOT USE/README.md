# The CJP Files

Independent, source-linked coverage of the Cockroach Janta Party movement and related public affairs in India.

Website: https://ashish-bhatia.github.io/the-cjp-files/

## The publication

- `index.html` — Editorial homepage and major stories.
- `timeline.html` — Filterable public chronology.
- `people.html` — Named public roles and disclosed appointments.
- `network.html` — Interactive map of documented public relationships.
- `claims.html` — Claims and source-linked factual assessments.
- `law.html` — Supreme Court decisions and reported police proceedings.
- `october-dossier.html` — October procedural evidence, public funding claim audit and pending documents.
- `school-audits.html` — Independent review of the School Thik Karo campaign and disputed school access.
- `international-record.html` — UN report A/81/186, India’s response and evidence limitations.
- `city-protests.html` — October 16–17 reporting from Delhi, Mumbai, Pune and Bengaluru; organisational and policing distinctions.
- `identity-finance.html` — Competing party-name registration application, ECI status and individually disclosed prior donation to AAP.
- `elections.html` — Special Intensive Revision and ECI controversy.
- `world.html` — Historical Indian and international comparisons.
- `sources.html` — Searchable public source library.
- `about.html` — Editorial standards, scope and corrections.
- `assets/site.css` — Responsive visual system.
- `assets/content.js` — Publicly sourced timeline, roles, claims, sources and relationships.
- `assets/site.js` — Filters, relationship explorer, accessible navigation, appearance controls.

All public stories contain links to the reported facts or primary records on which they rely. The relationship diagram differentiates appointments, historical affiliations, reported outreach and overlapping protest issues. Source links open at their original publishers. No private communications or personal addresses are published.

## GitHub Pages

This is a static site. No build system, dependencies or GitHub Actions workflow is required.

In the repository settings, choose **Settings → Pages → Build and deployment → Deploy from a branch**. Select **main** and **/(root)**. Save the choice.

GitHub's normal branch publishing is sufficient. The `.nojekyll` file instructs Pages to serve the static files without Jekyll processing.

## Editorial corrections

Submit specific corrections and documentary evidence using [GitHub Issues](https://github.com/Ashish-Bhatia/the-cjp-files/issues). Include the exact passage, dated original source and proposed correction. Do not submit confidential communications, private contact details or unsupported personal accusations.

This publication is independent of the Cockroach Janta Party, political parties, government agencies and the organisations mentioned in its reporting.
