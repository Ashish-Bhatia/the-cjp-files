# THE CJP FILES

An evidence-led, static investigative editorial publication about India's 2026 youth protest movement.

- Deployment target: GitHub Pages, `main`, `/ (root)`.
- No build process, external runtime or GitHub Actions deployment required.
- HTML pages are pre-generated in the publishing root. Files load `/the-cjp-files/assets/...`.
- Events, claims, relationships and source details are backed by static JSON in `data/`.
- Editorial review date: 2026-10-19.

All reporting represents the limited source base stated, not a comprehensive national census. Historical repository work was not reused.
